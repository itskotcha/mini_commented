# Shoe Customizer

<!-- คำอธิบายโปรเจกต์: แอป Flutter ออกแบบรองเท้า 3D ปรับสีรายชิ้นส่วน นำรูปมาทำสติกเกอร์ และวาดลายได้ -->
แอป Flutter สำหรับออกแบบรองเท้า 3D รองรับการปรับสีรายชิ้นส่วน นำเข้ารูปจากเครื่องเป็นสติกเกอร์ และวาดลายด้วยปากกาหลายชนิด

<!-- หัวข้อ: ฟังก์ชันตกแต่งที่แอปรองรับ -->
## ฟังก์ชันตกแต่ง

<!-- ฟังก์ชันที่ 1: เปลี่ยนสีด้วยวงล้อสี (โค้ดอยู่ใน customizer_screen.dart ส่วน _buildColorPanel) -->
- เปลี่ยนสีชิ้นส่วนรองเท้าด้วยวงล้อสี
<!-- ฟังก์ชันที่ 2: นำเข้ารูปและแตะวางสติกเกอร์ (เมธอด _importSticker และ _prepareSticker) -->
- นำเข้า PNG/JPG จาก Gallery แล้วแตะบนผิวรองเท้าเพื่อวางสติกเกอร์
<!-- ฟังก์ชันที่ 3: ลากย้าย ย่อขยาย หมุนสติกเกอร์ (แถบเลื่อนใน _buildStickerPanel และการลากใน shoe_painter_entry.js) -->
- ลากสติกเกอร์บนผิวรองเท้า และใช้แถบเลื่อนเพื่อย่อ–ขยาย/หมุน
<!-- ฟังก์ชันที่ 4: ทำสำเนาและลบสติกเกอร์ (ปุ่มใน _buildStickerPanel) -->
- ทำสำเนาหรือลบสติกเกอร์ที่เลือก
<!-- ฟังก์ชันที่ 5: ปากกา 4 ชนิด (enum BrushType ใน custom_design.dart และ drawStrokeOnState ใน shoe_painter_entry.js) -->
- วาดลายด้วยหัวกลม มาร์กเกอร์ ไฮไลต์ และสเปรย์
<!-- ฟังก์ชันที่ 6: ปรับสี ขนาด ย้อนกลับ และล้างลายวาด (_buildDrawingPanel) -->
- เลือกสีปากกาจากวงล้อ ปรับขนาด ย้อนกลับ และล้างลายวาด
<!-- ฟังก์ชันที่ 7: หน้าสรุปแสดงสติกเกอร์และลายวาดต่อจากหน้าตกแต่ง (summary_screen.dart) -->
- แสดงสติกเกอร์และลายวาดต่อในหน้าสรุปออเดอร์
<!-- หลักการสำคัญ: ลายทุกอย่างถูกวาดลง texture ตามพิกัด UV ของโมเดล จึงแนบกับผิวโค้งของรองเท้าได้จริง -->
- สติกเกอร์และลายวาดถูกเขียนลง texture ตามพิกัด UV ของโมเดล จึงแนบโค้งและหมุนตามผิวรองเท้าจริง
<!-- สติกเกอร์พื้นขาวถูกทำให้โปร่งใสอัตโนมัติ (ฟังก์ชัน loadStickerImage ใน shoe_painter_entry.js) -->
- รูปสติกเกอร์พื้นหลังสีขาวจะถูกทำให้โปร่งใสอัตโนมัติเพื่อให้ขอบดูกลืนกับรองเท้า

<!-- คำแนะนำการใช้งาน: วางสติกเกอร์หรือวาดเสร็จแล้วสลับไปแท็บสีเพื่อหมุนดูรองเท้า เพราะแท็บอื่นล็อกกล้องไว้ -->
หลังวางสติกเกอร์หรือวาดลายแล้ว ให้สลับไปแท็บ **สี** เพื่อหมุนตรวจดูรองเท้าได้ 360 องศา
<!-- ระบบรับลายวาดเฉพาะจุดที่รังสีชนผิวรองเท้าจริง (ฟังก์ชัน hitAt) -->
ระบบจะรับลายวาดเฉพาะจุดที่ชนกับผิวรองเท้าเท่านั้น

<!-- หมายเหตุ: ข้อความนี้ระบุเวอร์ชัน 1.3.2+6 แต่ pubspec.yaml ปัจจุบันเป็น 1.3.4+8 ส่วนเนื้อหาเรื่องไฟล์ที่ต้องคัดลอกทั้งโปรเจกต์ยังใช้ได้อยู่ -->
> เวอร์ชัน 1.3.2+6 ใช้ `assets/shoe_painter_v3_2.js` และ `assets/draco/` เพิ่มเติม
> จึงต้องคัดลอกทั้งโปรเจกต์/ZIP ไม่ใช่คัดลอกเฉพาะไฟล์ Dart

<!-- หัวข้อ: วิธีเปิดโปรเจกต์ -->
## วิธีเปิดโปรเจกต์

<!-- อธิบาย: ถ้ายังไม่มีโฟลเดอร์แพลตฟอร์ม (android, ios, web) ให้สร้างด้วยคำสั่งด้านล่าง -->
ไฟล์ชุดนี้เป็น source เดิมของโปรเจกต์ หากยังไม่มีโฟลเดอร์ `android`, `ios`, `web` ให้เปิด Terminal ในโฟลเดอร์นี้แล้วรัน:

<!-- บล็อกคำสั่ง: flutter create . สร้างโฟลเดอร์แพลตฟอร์ม, flutter pub get ติดตั้งแพ็กเกจ, flutter run รันแอป -->
```bash
flutter create .
flutter pub get
flutter run
```

<!-- อธิบาย: บน iOS ต้องเพิ่มข้อความขออนุญาตเข้าถึงคลังรูปใน Info.plist -->
สำหรับ iOS ให้เพิ่มข้อความต่อไปนี้ใน `ios/Runner/Info.plist` ภายใน `<dict>` เพื่ออนุญาตให้เลือกรูป:

<!-- บล็อกตัวอย่าง XML ที่ต้องเพิ่มลงใน Info.plist -->
```xml
<key>NSPhotoLibraryUsageDescription</key>
<string>ใช้เลือกรูปภาพเพื่อนำมาทำเป็นสติกเกอร์บนรองเท้า</string>
```

<!-- อธิบาย: Android รุ่นใหม่ใช้ Photo Picker ของระบบ จึงไม่ต้องขอสิทธิ์เพิ่ม -->
Android รุ่นปัจจุบันใช้ System Photo Picker ของ `image_picker` จึงไม่ต้องเพิ่ม permission สำหรับการเลือกรูปจาก Gallery
